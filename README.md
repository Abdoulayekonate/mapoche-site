# MaPoche : pages publiques

La page d'accueil de l'app MaPoche (présentation, badges des stores, aide `#aide`), sa politique de confidentialité et le fichier
`version.json` que l'app lit pour annoncer une mise à jour, publiés par GitHub Pages :
https://abdoulayekonate.github.io/mapoche-site/

La source est dans le dépôt privé de MaPoche (`stores/site/`) : la modifier là-bas, puis recopier ici `index.html`,
`confidentialite.html`, `version.json`, `img/` et `polices/`.
